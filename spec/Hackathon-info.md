### 🎯 Challenge & Theme

Participants build voice AI agents using AssemblyAI's real-time voice AI technology. Builders can choose from two main approaches depending on their architecture preference:

1. **Voice Agent API:** An end-to-end voice agent through a single connection, with AssemblyAI handling core voice interaction, STT, LLM routing, voice output, turn-taking, and JSON-Schema tool calling.
2. **Realtime Speech-to-Text API:** Use AssemblyAI's real-time STT over WebSocket as a foundation while bringing your own custom orchestration, LLM, and text-to-speech (TTS).

VoiceCare uses both, one per stage: Realtime STT with the medical domain for Stage 1 voice-note recording, and the Voice Agent API for Stage 2 turn-based clarification.
